# Product Inventory System

## Project Description

This is a PHP and MySQL-based Product Inventory System developed as part of the Full Site Implementation assignment. The system allows users to manage products with full CRUD functionality, advanced search features, and secure coding practices.

## Features Implemented

- Add new products
- View product list
- Edit existing products
- Delete products with confirmation
- Advanced search by:
  - Product name
  - Category
  - Price range
- AJAX live search (without page reload)
- Secure database access using PDO prepared statements
- Clean and responsive CSS design

## Technologies Used

- PHP (PDO)
- MySQL
- HTML5
- CSS
- JavaScript (Fetch API for AJAX)

## Security Measures

- SQL Injection prevention using prepared statements
- XSS prevention using output escaping
- Server-side form validation

## Optional Enhancements

- CSRF protection
- User authentication
